# AI 圆桌（一问九答）

把问题**同时**发给 9 家 AI（千问/豆包/元宝/智谱/Kimi/DeepSeek/MiniMax/文心/MiMo），产出五段结构总结（主要共识/次要共识/分歧观点/个性观点/综合意见）+ 各家原文附录。本机常驻服务，经本地 HTTP（127.0.0.1:8765）调用。

**何时用**：消息含上述触发词，或明确要求就某问题听取多家 AI 意见 -> 发起圆桌；想查以前问过什么/之前的结论 -> 查历史（文末）。

## 发起圆桌（异步三步）

**1. 提取问题**：剥离触发词。「AI圆桌 用一句话介绍杭州」-> 问题就是「用一句话介绍杭州」。默认问全部 9 家；用户指定某几家（如「只问千问和 MiMo」）时用 id：`qwen`千问 / `doubao`豆包 / `yuanbao`元宝 / `zhipu`智谱 / `kimi`Kimi / `deepseek`DeepSeek / `minimax`MiniMax / `wenxin`文心 / `mimo`MiMo。

**2. 受理（立即返回，不等待）**：

```bash
curl -sS --max-time 10 -X POST http://127.0.0.1:8765/ask \
  -H 'Content-Type: application/json' \
  -d '{"question":"<问题>","sites":["qwen","mimo"],"async":true}'
```

问题含双引号/反斜杠/换行必须 JSON 转义；`sites` 可省略（=问全部 9 家）。返回 `{"ok":true,"requestId":"async-xxx",...}`。

**3. 轮询取结果**（每 15~20 秒一次，`state:"running"` 继续等，`"done"` 取 `item`）：

```bash
curl -sS --max-time 10 'http://127.0.0.1:8765/ask/status?id=<requestId>'
```

一轮通常 1~3 分钟，个别深度研究 7~12 分钟。受理后先告知用户「已发出，各家作答中，通常几分钟」，等待期间不要反复播报进度。

> 备选：执行环境单条命令可阻塞 13 分钟时，也可不带 `async` 同步调用 `/ask`（一次调用阻塞至完成，返回字段同 `item`）。同步调用若被中途掐断，结果稍后仍可从 `/history` 查到。

## 结果解读与呈现

`item` 字段：
- `summary`：总结全文 = **五段正文 + 「附录：各家意见（原文）」**（附录含各家原文，整体可能上万字）
- `summaryFile`：总结 docx 绝对路径（含附录）；无总结或生成失败为空字符串
- `summaryError`：总结失败原因（此时 `replies` 里各家回答仍可用）
- `replies[]`：`state:"done"` 且 `text` 非空才算成功；失败家呈现时标注即可，不强求 9 家齐全

呈现规则：
1. **正文发文本**：截取 `summary` 第一个「附录：」**之前**的部分发给用户（通常几百到两千字）；超长按「一、~五、」分段多条发送，保持标题完整
2. **正文最前面加两三句导读**：点出主要共识与关键分歧，注明「共 N/9 家成功回复」；失败家一句带过（如「Kimi 超时未交卷」）
3. **渠道支持发文件且 `summaryFile` 非空** -> 把 docx 作附件一并发送，正文注明「全文见附件」
4. 用户想**深挖某家观点** -> 从对应 `replies[].text` 展开该家原文

## 查历史

```bash
curl -sS --max-time 10 'http://127.0.0.1:8765/history?limit=10'      # 列表（可加 &q=关键词，中文需 URL 编码）
curl -sS --max-time 10 'http://127.0.0.1:8765/history/item?id=<id>'  # 单轮完整内容（字段同 item）
```

列表先简要呈现（时间 + 问题 + 几家成功），用户选定后再取详情，呈现方式同上。

## 错误处理

- 受理返回 **429 busy**：另一轮进行中（或桌面端正被占用），告知用户稍候再发；**不要并发发起**
- **503 not-ready** 或接口连不上：AI 圆桌桌面应用未启动，提示用户先启动，不要继续发起
- 轮询返回 **404**：requestId 无效，或本轮超 15 分钟被看门狗释放，可建议用户重发
- `summary` 为空但 `replies` 有内容：照常呈现各家观点，注明总结失败及原因
