Why · 为什么用

为什么需要一张「圆桌」

单问一个 AI，你得到的只是一个观点；让八个 AI 同场作答，你得到的是交叉验证后的共识与分歧。

🔑

零成本开箱即用

不需要任何 API Key，直接复用你浏览器里已登录的网页版账号，用网页自动化模拟真人提问、抓取回复。零成本，开箱即用。

⚖️

八家独立作答

八家模型各自独立回答，共识留下、分歧标出，交叉验证有效缓解单一模型的幻觉与视角偏差，重要判断更踏实。

📋

自动五段总结

收齐回复后自动生成结构化综述：主要共识 / 次要共识 / 分歧观点 / 个性观点 / 综合意见，附录保留各家原文。

🖥️

桌面 + 接口双入口

GUI 满足日常使用，本地 HTTP 接口（127.0.0.1）供脚本与 Agent 集成，一套引擎两种玩法。

Install · 安装

三步装上，立刻开桌

普通用户用安装包；开发者走源码。各平台均已提供对应构建。

Windows
绿色版 zip，解压即用（推荐）：解压后双击 AI圆桌.exe 即可启动，无需安装；另有 Setup-x64.exe 安装版 可选（双击按向导安装）。
macOS
Apple Silicon zip：解压后把应用拖入「应用程序」文件夹即可使用。
Linux
deb 包（arm64，适配统信 UOS / Deepin）：sudo dpkg -i 安装（缺依赖时 sudo apt-get install -f），从应用菜单启动。
开发者
源码运行：git clone → bash install.sh → npm start（需 Node 18+ 与图形桌面）。
提示：关闭窗口并不会退出程序，应用会最小化到系统托盘常驻；从托盘菜单可「显示主窗口 / 退出」。

Overview · 界面总览

主界面：一区输入，八家作答，一栏总结

启动后主窗口自上而下分三层，两条分隔条均可拖拽调整区域高度。

  • 顶部输入区：左侧 ＋清空 按钮、中间问题输入框、右侧按钮组 发送 · 总结 · 设置 · 历史。
  • 模型栏：显示「已选 8/8」计数与 8 个模型按钮；单击任一按钮 = 全屏打开该家网页（用于登录 / 查看 / 补发）。
  • 左侧：各家回复进度与内容预览，单击某家行可跳转总结附录中该家原文。
  • 右侧：总结面板（五段结构 + 目录跳转 + 复制 / 存为 MD）。

Login · 登录

登录 8 家账号（一次即可）

AI 圆桌不申请任何 API Key，而是复用你各家网页版已登录的账号；登录态持久保存，重启不丢。

  • 单击模型栏中对应模型按钮（如「豆包」「DeepSeek」）。
  • 弹出该家的全屏网页浮层。
  • 在浮层内像平时一样扫码 / 账号登录该 AI 网页版。
  • 登录成功后点浮层右上角 × 关闭，回到主窗口。
screenshot 05 · 单家全文——单击模型按钮弹出的全屏网页浮层（登录 / 补发用）
8 家逐一登录一次即可，登录态持久保存、重启不丢。掉线了？再单击该家按钮重新登录一次。
总结用的 DeepSeek 第二账号：点右侧总结面板标题 「📋 总结」 全屏展开 DeepSeek 总结账号页面，手动登录第二个 DeepSeek 账号（只登录、不触发总结）。

Settings · 设置

设置：决定谁上桌、怎么发、怎么总结

右上角「设置」弹窗集中管理参与模型、快捷键与总结方式。

  • 参与各家：勾选决定哪些模型上场，全选 / 清空 一键切换；顶部「已选 N/8」实时更新。
  • 发送快捷键：Ctrl+Enter 发送（Enter 换行）或 Enter 发送（Shift+Enter 换行）两种习惯。
  • 自动总结：默认开启，各家全部交卷后自动生成五段总结，无需手动点「总结」。
  • API 总结（备选）：默认指向智谱免费模型 GLM-4.7-Flash，填入你自己的 Key 即改用 API 总结；也可改填任意 OpenAI 兼容接口。

Ask · 提问与进度

输入问题，八家同时开答

一个问题广播给所有参与模型，左侧逐家出现回复预览与实时进度。

  • 在输入框写入问题 → Ctrl+Enter 发送（或在设置里改为 Enter 发送）→ 八家同时开答。
  • 状态胶囊：待发送 → 发送中 → 生成中 Ns → 已完成 ✓。
  • 超过 90 秒 会提示「仍在生成」，不是卡死，请耐心等待。
  • 某家失败：整行红边 + 醒目「↻ 重发」按钮，只重发该家，不影响其他家。
  • 发送后问题保留在输入框，方便继续追问；点 ＋ 清空开新题。

Notes · 温馨提示

使用前，请收下这几条提醒

安全第一，理性使用。

  • ⚠️合规：自动化操作消费级网页版 AI，仅供个人学习研究，勿商用批量抓取，请自行评估并遵守各家服务条款。
  • 🔒安全：HTTP 接口仅绑定 127.0.0.1，不暴露到网络；API Key 只存本机，源码不含硬编码密钥。
  • 🧩依赖网页结构：强依赖各家网页布局，网站改版需适配，等待更新即可，期间可手动在全屏页补发。
  • ⏱️节奏：一轮约 1–7 分钟，单轮串行，一次一题；同一时间只跑一轮，重复请求会返回 busy。
